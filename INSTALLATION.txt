HOMEKEYS - XENO PIANO ENGINE v2.0
==================================

INSTALLER DANS FL STUDIO
------------------------
1. Copie le dossier "HomeKeys.vst3" dans :
      C:\Program Files\Common Files\VST3\
2. Ouvre FL Studio > Options > Manage plugins (ou "Gerer les plugins").
3. Clique sur "Find installed plugins" (Rechercher). HomeKeys apparait dans
   la liste : coche l'etoile pour l'ajouter a tes favoris.
4. Dans le Channel Rack : "+" > HomeKeys. C'est pret.

HomeKeys.exe = version autonome (sans FL), pratique pour tester.

LES 5 PIANOS
------------
DOUX         piano feutre, intime, sombre
GRAVE        profond, sub-basse, long sustain
ORCHESTRE    piano de concert brillant + cordes
CINEMATIQUE  piano + nappe sombre, grand espace
DREAMING     piano reveur, shimmer, chorus, reverb immense

LES BOUTONS
-----------
TONE      brillance du piano          CHORUS   ondulation / largeur
VELOCITY  sensibilite a la frappe     REVERB   quantite d'espace
RELEASE   duree apres relachement     SIZE     taille de la salle
LAYER     quantite de nappe/cordes    VOLUME   volume general
WIDTH     largeur stereo
La pedale de sustain (CC64) est geree.

GRAIN
-----
OCTAVE    transpose de -2 a +2 octaves (boite a musique, trap grave...)
DRIVE     saturation chaude de bande magnetique
WOW       ondulation de cassette (pleurage)
CRUSH     grain numerique lo-fi
VINYL     souffle et craquements de vinyle

PRESETS
-------
PACK "HomeKey Preset" (63 presets) : il s'installe TOUT SEUL au premier
lancement. Classement : Keys, Bass, Leads, Bells, Pads, Plucks, Lo-Fi,
Cinematic, Chops, Constellation. Le style est entre crochets : [Trap]...
- IMPORT : ajoute un dossier, un .zip ou des .hkpreset (confirmation OK).

ONGLETS
-------
PIANO          : corps, espace et grain
SYNTH          : filtre LP/BP/HP, attack, decay, hammer, sub, unison,
                 fine, delay ping-pong synchronise au tempo
CONSTELLATION  : LFO aleatoire. Glisse les etoiles (loin du centre =
                 plus intense). DEPTH = quantite, RATE = vitesse, RANDOM.
CHOP           : CHOP ON = chop permanent, ou joue dans le piano roll :
                 C1 Gate, C#1 Pattern, D1 Stutter, D#1 Reverse,
                 E1 Tape Stop, F1 Half Speed, F#1 Octave Up, G1 Glitch

- 15 presets d'usine (3 par piano), fleches < > pour naviguer.
- SAVE : sauvegarde ton son comme nouveau preset.
- DEL  : supprime un de tes presets.
- DOSSIER : ouvre Documents\HomeKeys\Presets
  Tu peux y ajouter / partager des fichiers .hkpreset : ils apparaissent
  automatiquement sous "MES PRESETS".
